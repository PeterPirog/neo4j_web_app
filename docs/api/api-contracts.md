# API Contracts

FastAPI exposes canonical JSON endpoints under `/api/v1`.

Legacy `/api` endpoints are kept as compatibility aliases and are hidden from
OpenAPI.

FastAPI is the only public contract between the web app and Neo4j. The frontend
does not know Cypher, Bolt, Neo4j credentials or database internals.

## Health

- `GET /api/v1/health`

## People

- `GET /api/v1/people`
- `POST /api/v1/people`
- `GET /api/v1/people/{person_id}`
- `PATCH /api/v1/people/{person_id}`
- `DELETE /api/v1/people/{person_id}`

`Person` payload fields:

- `name` is required when creating a person.
- `email` is optional.
- `note` is optional.
- `id` is generated by Neo4j and returned by the API.

`PATCH /api/v1/people/{person_id}` is a partial update. `null` values currently
mean "leave the old optional value unchanged" in the repository query.

## Cities

- `GET /api/v1/cities`
- `POST /api/v1/cities`
- `GET /api/v1/cities/{city_id}`
- `PATCH /api/v1/cities/{city_id}`
- `DELETE /api/v1/cities/{city_id}`

`City` payload fields:

- `name` is required when creating a city.
- `country` is optional.
- `note` is optional.
- `id` is generated by Neo4j and returned by the API.
- `residents_count` is derived from incoming `MIESZKA_W` relationships.

## Relations

- `GET /api/v1/relations`
- `POST /api/v1/relations`
- `DELETE /api/v1/relations/{relationship_id}`

Allowed relationship types:

- `KNOWS`
- `WORKS_WITH`
- `MANAGES`
- `REPORTS_TO`
- `RELATED_TO`

`POST /api/v1/relations` creates or updates one relationship of the selected
type between the same source and target `Person`. The relationship type is
validated in Pydantic and again before building the Cypher query.

## Residences

- `GET /api/v1/residences`
- `POST /api/v1/residences`
- `DELETE /api/v1/residences/{person_id}/{city_id}`

Residences manage the static relationship:

```cypher
(:Person)-[:MIESZKA_W]->(:City)
```

`POST /api/v1/residences` uses `MERGE`, so assigning the same person to the same
city again refreshes the relationship timestamp instead of creating a duplicate.

## Generate Client

Start FastAPI on port 8000 and run:

```powershell
npm run generate:api-client
```

The frontend uses API contracts and generated types. It must not contain Cypher.

Regenerate the client whenever a router path, request schema or response schema
changes. Commit the generated `packages/api-client/src/schema.d.ts` with the API
change so the frontend and backend stay in sync.
