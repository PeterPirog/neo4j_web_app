# Codex Prompt: Add Feature

Dodaj funkcję do projektu FastAPI + Neo4j.

Zasady:

- Najpierw przeczytaj `AGENTS.md` i `.ai/ARCHITECTURE.md`.
- Nie używaj Django, SQLAlchemy, neomodel, OGM ani GraphQL.
- Nie dodawaj MCP Neo4j jako zależności runtime.
- Dostęp do Neo4j implementuj przez oficjalny async driver.
- Zapytania Cypher trzymaj w warstwie serwisowej.
- Parametryzuj wszystkie dane użytkownika.
- Nie modyfikuj `.env`.
- Nie instaluj pakietów bez zgody.

Oczekiwany rezultat:

- Zmiana kodu zgodna z istniejącymi wzorcami.
- Aktualizacja dokumentacji lub plików Cypher, jeżeli funkcja zmienia model danych.
- Podstawowa weryfikacja działania.
