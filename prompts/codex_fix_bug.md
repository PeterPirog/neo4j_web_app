# Codex Prompt: Fix Bug

Napraw błąd w projekcie FastAPI + Neo4j.

Procedura:

1. Odtwórz lub zlokalizuj błąd na podstawie kodu i opisu.
2. Sprawdź, czy problem jest w endpointach, serwisach, szablonach czy konfiguracji Neo4j.
3. Zachowaj async driver i parametryzowany Cypher.
4. Nie modyfikuj `.env`.
5. Nie wykonuj destrukcyjnych zapytań.
6. Nie instaluj pakietów bez zgody.

Po naprawie:

- Uruchom dostępną weryfikację.
- Opisz przyczynę błędu i zmienione pliki.
- Wskaż, jeżeli czegoś nie dało się sprawdzić lokalnie.
